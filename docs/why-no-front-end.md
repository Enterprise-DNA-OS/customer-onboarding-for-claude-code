# Why no front end

An implementation lead can review tasks, record evidence, chase dependencies and prepare handover from the database and an agent. Static HTML gives the team a printable snapshot without running an application server.

A screen adds live shared editing, drag and drop, mobile access, customer self-service and notifications. This base supplies none of those. HTML snapshots do not refresh until regenerated. A laptop database is for one operator; shared Postgres needs role and access design.

Enterprise DNA builds a customer website and the connections your business needs as part of your custom version. The owned database remains the source of the records.
